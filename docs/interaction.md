# 小黑桌边玩法

适用于 Windows 独立桌面版 3.9。

靠近小黑，头顶从左往右依次出现变身（双箭头）、分身（分叉的尾巴）、皇受（猫脸）、比丢（圆团）和工具（手提包）。停留在图标上可查看用途。轻点小黑会回应，双击小跳，拖动搬家。右键能喂鱼干、跑步、休息或打开口袋。「陪伴」页底部可展开全部动作。

**变身与分身**　点「变身」来回切换猫形和人形。人形会长高，两种形态共用「桌宠大小」设置。点「分身」时留意尾巴，尾尖贴地回钩并鼓起，三个嘿咻先后离开尾尖，和原本待在右脚旁的嘿咻聚成四只。再点可召回。切换到其他互动时，旧动作会收起。

**皇受与比丢**　点「皇受」叫来小皇，点角色或同一个按钮，它会扑接叶子，再靠近小黑蹭蹭。点「比丢」能换伙伴，继续点就能看到它吞食、鼓肚，毛色跟着食物改变。右键访客可结束。轻点猫形小黑脚边的嘿咻，它会沿着耳朵跳上头顶、合眼打盹，再落回脚边。趴着时再点它可提前叫醒。右键菜单里的「嘿咻捉迷藏」可以玩找三次的小游戏。

**位置与大小**　将小黑拖近底部任务栏后松手，它会贴住任务栏上沿。向上拖开即可自由摆放。右键调节「桌宠大小」滑块，或把指针放在小黑身上按 Ctrl 滚动滚轮，范围是 28%–100%。设置页也能切换「贴住任务栏上沿」。

**专注陪伴**　点「工具」，选择或输入 1–180 分钟并开始。口袋会自动收起，小黑头顶显示剩余时间。点计时器打开口袋，暂停、继续或结束本轮。

**天气**　打开工具页，会尝试使用 Windows 已许可的位置查询当地天气。位置不可用时可以输入城市，结果显示来源和时间。查看新天气需要联网。

## 互动声音

轻点猫形小黑，它偶尔会打滚应声。右键选「找师父练习」看无限接住它。人形相见时挥手并显示台词，已导入录音时也会开口。[声音说明](sound.md)

## 它也会自己动

眨眼与轻微待机变化自动播放。默认开启的偶发动作会在空闲时主动回应；开启散步后会自己在附近走走。

安静模式、专注计时、休息、拖动、编辑工作台或正在播放你指定的动作时，不会插播随机回应。你刚互动过，也会先安静待一会儿。

专注计时启动后，会自动使用专注工作动画；计时结束会招手。它是本机的专注计时，不是读取Codex聊天进度。

## Codex原生版为何点一下只有小跳

原生版的动作触发由Codex / ChatGPT桌面应用控制。皮肤包提供图集、名字和版本，不包含单击、双击、长按的事件绑定。

你看到的点击小跳属于宿主当前交互。聊天工作中、需要输入、完成未读或出错时，应用会自动使用相应的工作、等待、检查或受阻动作。它们不是一个供皮肤自行控制的手动动作菜单。[官方状态说明](https://learn.chatgpt.com/docs/pets#understand-pet-status)

所以，独立桌面版可提供上述轻点、双击、长按和快捷按钮；仅替换原生皮肤不能把同样的自定义操作接进Codex。这里不把左右拖动反馈当成新增的互动玩法。
