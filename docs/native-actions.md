# 原生版：动作怎样触发

## 左右跑步

按住桌面浮窗中的小黑，持续向左或向右拖动。桌面应用根据横向拖动方向使用 `running-left` 或 `running-right`；松开后回到应用决定的状态。只上下拖动不保证触发左右跑步。

上述方向触发已核对本次安装的桌面版本实现。它不是一个可供第三方程序调用的公开动画 API；未来版本的具体手感可能变化。官方说明提供了拖动萌宠移动位置的入口。[Pets 文档](https://learn.chatgpt.com/docs/pets)

## 专注工作与任务状态

任务运行使用的是另一行 `running` 动画，也就是本作品的专注工作动作。原生应用自行决定工作、需要输入、完成未读、受阻等表现。通过浮窗的铃铛可查看聊天活动并进入对应聊天。[状态与活动列表](https://learn.chatgpt.com/docs/pets)

## 招手、跳跃与视线

- 初次唤醒的欢迎反馈会用到招手动作。
- 图集中包含跳跃、检查、十六方向视线等帧；是否由某个具体交互触发，由原生应用控制。
- 没有验证过原生 `/run`、`/jump`、`/wave` 命令，使用说明不承诺这些命令存在。
- `/pet` 负责显示或隐藏浮窗，不是手动切换动作的命令。
- 原生皮肤清单没有单击、双击、长按的事件绑定字段。仅替换图集不能把这些操作改成自定义动作；用户观察到的点击小跳属于宿主交互。
- 想直接触发不同回应，请使用独立版 3.6 的悬停快捷栏。右键打开口袋可以展开「全部动作」。[独立版交互](interaction.md)

## 少动画与显示异常

系统的“减少动态效果”设置可能让原生萌宠显示静帧；原生大小可在 Pets 自定义设置中调整。[原生设置说明](https://learn.chatgpt.com/docs/pets)

若预览正确而浮窗仍为默认机器人，先在 Pets 页点 Refresh，再完整退出并重开应用。重复隐藏、显示不会保证重建浮窗。
