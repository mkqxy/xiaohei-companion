# 安装、更新和卸载

## 原生外观包

解压 Native ZIP，双击 `Install-Native.cmd`。脚本默认把两个文件安装到：

```text
%USERPROFILE%\.codex\pets\xiaohei-heixiu\pet.json
%USERPROFILE%\.codex\pets\xiaohei-heixiu\spritesheet.webp
```

如果设置了环境变量 `CODEX_HOME`，使用该目录下的 `pets`。安装完成后，进入应用设置的 Pets 页，点 Refresh 并选择「小黑和嘿咻」。输入 `/pet` 显示浮窗。[官方选择入口](https://learn.chatgpt.com/docs/pets)

安装器只复制这个角色包。它会检查 v2 清单、WebP 尺寸和复制前后的 SHA256，不改 `config.toml`、账号、当前选中项、注册表或开机启动。

### 重复安装与更新

内容完全相同会直接结束，不产生重复备份。内容不同时，旧角色目录移到相应 Codex 目录的 `pet-backups`，再提交新目录。备份在 `pets` 外，不会额外出现在萌宠列表。写入失败会尝试恢复原目录，并报告错误。

### 不用脚本，手动安装

把 `native/xiaohei-heixiu` 整个文件夹复制到自己的 `pets` 文件夹即可。已有同名目录时先保留备份。然后刷新萌宠列表。

### 卸载

先在应用中选择其他萌宠，再删除自己的 `pets/xiaohei-heixiu` 目录。若应用已把本地萌宠同步到账号中，云端条目和本地文件是分别管理的；仅删除本地目录不等于删除账号条目。项目安装器不会替用户删除云端数据。

## 独立桌面版

解压 Portable ZIP，双击 `XiaoheiCompanion.exe`。默认图集嵌入程序，`editor`、`profiles` 和 `assets` 提供编辑与替换入口，建议保留整个目录。无需管理员权限。

设置和随手记保存在本机用户数据目录；可以从程序设置中的数据文件夹按钮打开。退出程序后删除解压目录即可移除程序。数据目录应在确认不再需要笔记后单独处理。

旧版独立程序的笔记和设置不由原生安装器处理，也不会上传到账号。

## 加载时仍显示机器人

1. 确认设置页中选择的是「小黑和嘿咻」，预览也为小黑。
2. 点击该页的 Refresh／刷新，等待图片和选择重新同步。
3. 若浮窗仍为旧形象，完整退出应用再打开；只关闭主窗口或隐藏浮窗可能保留原进程。

如果完整重启后仍失败，请提供应用版本、设置页预览、重启后的浮窗截图，以及安装器报错。不要把账号凭据或整份用户配置发到公开问题区。
