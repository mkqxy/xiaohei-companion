# 小黑的声音

轻点猫形小黑，轮到回应时它先抬眼，短短叫一声，侧身打个滚。叫声约 0.64 秒，先升高再放低。双击跳跃和散步时安静。

点「变身」，小黑用气泡介绍自己。右键「找师父练习」，猫形小黑直接跃入无限掌心，人形小黑挥手回应「师父第一！」。给对应动作导入 WAV 后，台词会按动作时机播放，嘴形跟随音节。

- 皇受扑叶、比丢吃果子、无限接猫和嘿咻打盹都默认安静。可给喜欢的动作单独导入录音。
- 在一个动作完成前切换到其他动作，属于上一个动作的待播声音会取消。专注、休息、隐藏或安静模式会收声。

## 调整和替换声音

右键小黑，选择「打开小黑的口袋 → 设置」。在「小黑的声音」可以关闭互动音效，或调节音量（默认 30%）。先从列表里选中一个声音，再点「听听小黑的声音」试听。手动试听仍遵循音量和开关，在专注和安静陪伴中也能操作。

要使用自己的录音，展开「自定义声音」，点「换成本地 WAV」，选用 5 秒以内的文件（16 位未压缩 PCM、单声道或立体声、8–96 kHz）。选好的声音立即适用于这个动作。「恢复默认」可以撤销这项更换。音量、开关和各项声音的替换各自独立；已导入的声音会随本机更新保留。文件存在本机用户数据目录的 sounds 子文件夹。
