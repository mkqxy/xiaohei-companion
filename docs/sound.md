# 小黑的声音

Windows 独立版 3.8 的猫形小黑偶尔会用一声真实的猫叫回应。轻点时反应会轮换，其中招手回应配有一声约 0.8 秒的幼猫叫；长按会听见低低的呼噜。人形和导入的其他外观会安静地做动作。散步、双击小跳、变身、尾巴分身以及伙伴进场都保持安静。

- 轻点脚边的嘿咻，它应一声，跳上小黑头顶合眼打盹。再次轻点头顶的嘿咻可以提前叫醒它。
- 喂小鱼干或给比丢投喂时会有轻咬声。皇受扑叶子时保持安静，靠近蹭蹭时有一小段呼噜。找到捉迷藏的嘿咻时有一声短回应。
- 专注结束会响一次轻铃。开始专注、休息、隐藏或开启安静陪伴后，普通互动会收声。连续点击有短暂的声音间隔。

## 调整和替换声音

右键小黑，选择「打开小黑的口袋 → 设置」。在「小黑的声音」可以关闭互动音效，或调节音量（默认 30%）。先从列表里选中一个声音，再点「听听小黑的声音」试听。手动试听仍遵循音量和开关，在专注和安静陪伴中也能操作。

要使用自己的录音，展开「自定义声音」，点「换成本地 WAV」，选用 5 秒以内的文件（16 位未压缩 PCM、单声道或立体声、8–96 kHz）。选好的声音立即适用于这个动作。「恢复内置声音」可以撤销这项更换。音量、开关和五个声音的替换各自独立；已导入的声音会随本机更新保留。文件存在本机用户数据目录的 sounds 子文件夹。

小黑应声的真实录音来自 George Miquilena，按 CC0 发布；其余四款内置音效由本项目合成。角色声音属于同人配音设计，所有素材均可离线播放。[录音出处及剪辑说明](../assets/sound/SOURCE.md)
