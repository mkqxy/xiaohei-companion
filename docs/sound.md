# 小黑的声音

轻点猫形小黑，轮到回应时它先抬眼，短短叫一声，侧身打个滚。叫声约 0.64 秒，先升高再放低。长按听呼噜，双击跳跃和散步时安静。

点「变身」，等人形露出脸，小黑会开口说「我叫小黑，我也是妖精」。两句话之间嘴巴合上，再开始第二句。右键选「找师父练习」，猫形小黑跃进无限的臂弯，一起看铁环；人形会朝师父挥手、喊一声「师父」。

- 嘿咻离开地面后应一声，再趴到头上打盹。比丢的食物进入嘴里、小黑的鱼干变小时，才听到咬合声。皇受靠过来蹭脸时会轻轻呼噜。
- 在一个动作完成前切换到其他动作，属于上一个动作的待播声音会取消。专注、休息、隐藏或安静模式会收声。

## 调整和替换声音

右键小黑，选择「打开小黑的口袋 → 设置」。在「小黑的声音」可以关闭互动音效，或调节音量（默认 30%）。先从列表里选中一个声音，再点「听听小黑的声音」试听。手动试听仍遵循音量和开关，在专注和安静陪伴中也能操作。

要使用自己的录音，展开「自定义声音」，点「换成本地 WAV」，选用 5 秒以内的文件（16 位未压缩 PCM、单声道或立体声、8–96 kHz）。选好的声音立即适用于这个动作。「恢复内置声音」可以撤销这项更换。音量、开关和各项声音的替换各自独立；已导入的声音会随本机更新保留。文件存在本机用户数据目录的 sounds 子文件夹。
