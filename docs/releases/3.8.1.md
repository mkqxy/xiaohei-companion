# 小黑桌面伙伴 3.8.1

在 Windows 10 或 11 上下载 `Xiaohei-Windows.zip`，全部解压，双击「启动小黑.cmd」。用过旧版的话，先右键旧版小黑，选「退出小黑」。随手记、大小和专注设置会继续使用。

- 右键小黑，点「在桌面散步」，移开鼠标就能看它走。停在它身上时，它也会停下来等你。
- 轻点猫形小黑，招手时会用真实幼猫录音应声。长按听呼噜，喂鱼干听轻响。走路、跳跃和变身保持安静。
- 点猫形小黑脚边的嘿咻，它会跳上头顶，合眼打盹，再跳下来。提前点一下头上的嘿咻可以叫醒它。
- 在「口袋 → 设置 → 小黑的声音」里可以试听每个动作，也可以单独更换或恢复本地 WAV。

`Xiaohei-Codex-Pet.zip` 是 Codex 原生萌宠外观。上述桌面互动在 Windows 独立版中提供。源码及离线编辑器在 `Xiaohei-Source.zip`。

这一版也修正了连续调用动作时偶尔颠倒的执行次序。

《罗小黑战记》非官方同人作品。猫叫录音、原创拟音和角色素材来源见包内 ASSET_NOTICE.md。
