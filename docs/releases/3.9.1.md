# 小黑桌面伙伴 3.9.1

右键小黑，选「找师父练习」。猫形小黑会追着金属环跃起，无限伸手接住它。人形小黑见到他会挥手喊「师父」。

这次按照《学前篇》的形象重画了无限。中分长发垂在脸侧，灰绿色的眼睛看向小黑，宽袖青灰长衫里露出浅色交领。封面和演示视频把这段互动放进一处有天光的灰绿石场。演示所用的角色与场景为 AI 辅助制作的同人美术。[正片第 43 话《跟师父一起做任务啦》](https://www.bilibili.com/zh-Hans/bangumi/play/ep6762152)

下载 `Xiaohei-Windows.zip`，全部解压，双击「启动小黑.cmd」。已经开着旧版时，先右键小黑选「退出小黑」。本机随手记和设置会接着使用。想查看或修改代码，可下载 `Xiaohei-Source.zip`。[带互动音效的演示](https://github.com/mkqxy/xiaohei-companion/blob/v3.9.1/media/demo.mp4)
