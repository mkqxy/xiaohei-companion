# 小黑桌面伙伴 3.9

点「变身」，小黑开口自我介绍。右键选「找师父练习」，猫形小黑会追着铁环跃进无限臂弯，人形小黑见面时会喊「师父」。轻点猫形小黑偶尔会触发一声短叫，嘴巴跟着音节开合。

在「口袋 → 设置 → 小黑的声音」可以单独试听猫叫、人形自我介绍和喊师父，也可以换成自己的 WAV。专注时保持安静。

下载 `Xiaohei-Windows.zip`，全部解压，双击「启动小黑.cmd」。从旧版升级时，先右键旧版小黑选择「退出小黑」。本机的随手记与设置会继续使用。

下载 `Xiaohei-Codex-Pet.zip` 可以在 Codex 原生萌宠中使用小黑外观；师徒互动、声音和变身由 Windows 独立版提供。源码在 `Xiaohei-Source.zip`。

本作品为《罗小黑战记》非官方同人桌宠。素材归属见包内 ASSET_NOTICE.md。
