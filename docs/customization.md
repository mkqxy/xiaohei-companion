# 个性化配置与替换角色

## 不写代码的使用方式

打开 `editor/index.html`，调整配置并看实际图集预览，导出 JSON 后在独立版设置中导入。也可先复制 `profiles/default.json` 编辑。普通文本编辑器就能打开 JSON；保存为 UTF-8。

配置只影响独立版。Codex 原生包的菜单和任务状态由桌面应用管理。

## 配置例子

```json
{
  "schemaVersion": 1,
  "name": "小黑",
  "greeting": "今天也陪着你。",
  "animationSpeed": 1.0,
  "scale": 0.36,
  "roaming": false,
  "quiet": false,
  "focusMinutes": 25,
  "waterMinutes": 0,
  "autoExpressions": true,
  "customActions": [
    {"label": "打个招呼", "animation": "waving", "message": "嗨，今天也见面啦。"},
    {"label": "陪我开工", "animation": "running", "message": "我在旁边陪你专注。"}
  ]
}
```

`name` 和 `greeting` 设置称呼与欢迎语；`animationSpeed` 调节帧播放速度；`scale` 设置大小；`roaming` 开关附近散步；`quiet` 减少气泡；`focusMinutes` 设置默认专注时长；`waterMinutes` 为 0 时关闭喝水提醒；`autoExpressions` 开关自动动作反馈。

`customActions` 每项包含按钮文字、已有动画和可选台词。按钮只播放图集并显示文字，不执行配置内的脚本、命令、URL 或外部程序。超出数量、长度、数值范围或不在支持列表的动作应由导入器拒绝或规范化，具体以导入反馈为准。

当前范围：名字最多 24 字符、欢迎语 160 字符；速度 0.5–2 倍，大小 0.28–1；专注 1–180 分钟；喝水提醒为 0（关闭）或 5–240 分钟。最多 12 个自定义动作，按钮文字最多 20 字符、台词 160 字符；配置文本不超过 64 KiB。超出数值范围会被限制到范围内，文本会截到上限；不认识的字段和动画 ID 会被拒绝。

支持的动画 ID：`idle`、`running-right`、`running-left`、`waving`、`jumping`、`failed`、`waiting`、`running`、`review`。为方便理解，`working` 可作为 `running` 的别名。

## PNG 图集规格

整张图片为透明 PNG，**1536 × 2288**；8 列 × 11 行；每格 **192 × 208**。角色应完整位于单格内，同一角色的比例、基线、颜色和道具保持一致。不要把棋盘格画进背景。

从第 0 行开始：

- 0：待机，6 帧；第 6 列是原生 v2 工具的中性视线副本，不计入待机动画。
- 1：向右跑，8 帧。
- 2：向左跑，8 帧。
- 3：招手，4 帧。
- 4：小跳，5 帧。
- 5：受阻／沮丧，8 帧。
- 6：等待输入，6 帧。
- 7：专注工作，6 帧，和脚步跑动不同。
- 8：检查，6 帧。
- 9：八个视线方向，000、022.5、045、067.5、090、112.5、135、157.5 度。
- 10：八个视线方向，180、202.5、225、247.5、270、292.5、315、337.5 度。

000 是向上，090 向屏幕右，180 向下，270 向屏幕左。中性正面不属于这十六个方向。没有使用的标准动画格保持全透明。

独立版导入时先验证尺寸和透明背景。检查不通过时应继续使用当前皮肤，避免出现空白桌宠。应用自带默认图集嵌入程序，可作为恢复入口。角色图片的导入不等于取得其版权，使用自己的或已获许可的图片。[素材许可范围](../ASSET_NOTICE.md)

独立版 3.6 保留导入的图集。用自己的皮肤时，点「变身」可体验小黑人形，再点就回到原来的角色。「分身」会临时请内置小黑出场，嘿咻回到尾巴后会恢复你的图集。

## 为原生版制作其他角色

原生版本需要同样的 v2 图集和清单，包含唯一 ID、名字、说明、`spriteVersionNumber: 2`、相对 `spritesheetPath`。改变清单名字不等于改变图片。请为新角色使用独立目录和 ID，避免覆盖现有角色。

本项目内置安装器只安装随包的 `xiaohei-heixiu`，不会扫描未知皮肤并自动执行它们。开发者如扩展安装器，应继续校验清单和相对路径，保留旧文件并避免改账号或应用全局状态。
