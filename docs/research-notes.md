## 原生萌宠：怎样触发跑步

**按住桌面上的萌宠，连续向右或向左拖动，就会使用相应方向的跑步动画。** 只上下拖动不保证进入左右跑步。放开鼠标后，拖动动画覆盖状态会清除，再回到应用决定的状态。

这一点由本机安装的桌面应用 26.1111.2228.0 静态代码核实：`webview/assets/async/884042.6102d9bc30.js` 的浮窗拖动处理，在一次指针移动的横向位移达到约 4 屏幕像素时设置 `running-right` 或 `running-left`，松开时清除覆盖。它是本版实现细节，不是对所有版本的公共 API 承诺。官方文档也确认可拖动萌宠移动位置。[Pets 官方文档](https://learn.chatgpt.com/docs/pets)

**任务“正在工作”使用另一类动作。** `running` 对应第 7 行的专注工作动画，不是第 1、2 行的左右跑步。应用依据聊天状态自动选择正在工作、等待输入、完成未读、受阻等表现；通过铃铛活动列表查看各聊天进展。[Pets 状态说明](https://learn.chatgpt.com/docs/pets)

其他已核实的边界：

- 初次唤醒的欢迎通知使用 `waving` 招手。本机浮窗代码把欢迎通知保留约 8 秒；它不等于随时可用的“招手命令”。
- 图集中有跳跃动作。共享精灵组件在显式启用悬停反馈时可切换到 `jumping`，但本次没有核实桌面浮窗暴露独立的跳跃按钮。因此不在使用说明中承诺“悬停桌面小黑必定跳跃”。
- 未找到原生 `/run`、`/jump`、`/wave` 命令。`/pet` 用于显示或隐藏浮窗，不是选择动画。[Pets 官方文档](https://learn.chatgpt.com/docs/pets)
- 官方页面包含方向键互动示例文字，但本次只直接验证了桌面浮窗的鼠标拖动路径。不要把方向键示例扩写成通用的全局快捷键。
- 系统开启减少动态效果时，原生萌宠可能使用静帧。[减少动画说明](https://learn.chatgpt.com/docs/pets)

### 本项目采用的原生时间参数

同一安装版本 `907538.0572f09d40.js` 的原生精灵组件定义如下，可用于独立版保持接近的动作节奏：

- 待机：基础帧时长 `[280,110,110,140,140,320]` 毫秒，原生待机播放时各乘 6。
- 左/右跑步与专注工作：每帧 120 毫秒，末帧 220 毫秒。
- 招手与跳跃：每帧 140 毫秒，末帧 280 毫秒。
- 受阻：每帧 140 毫秒，末帧 240 毫秒。
- 等待输入：每帧 150 毫秒，末帧 260 毫秒。
- 检查：每帧 150 毫秒，末帧 280 毫秒。

独立版可增加明确的动作按钮，用这份真实图集演示跑步、招手、小跳和工作状态。按钮效果属于本项目独立版，不作为原生 Codex 菜单扩展宣传。

## 开源桌宠参考

### VPet：动画、文本、功能分别可扩展

[VPet 官方仓库](https://github.com/LorisYounger/VPet) 提供 WPF 桌宠核心，README 说明模组可以修改动画、说话文本、主题、工作和功能插件；动画文件另有版权声明。这说明“软件代码开源”和“角色素材授权”应分别交代。

本项目采用的设计：名字、台词、动画速度、动作按钮和功能开关用可读配置承载；普通用户先用界面编辑，开发者再改源码。代码许可与小黑同人素材说明分开。这里没有继承或宣称取得 VPet 代码或美术的授权。

### Shimeji Rust：先让用户下载就能运行

[Shimeji Rust 官方仓库](https://github.com/JuenTingShie/shimeji_rs) 的 README 明确介绍独立 Windows 可执行程序、角色 ZIP 导入、统一的大小/速度设置、托盘入口与右键跳跃。角色包包含清单、动作配置和精灵文件。

本项目采用的设计：把“原生外观包”“独立桌面程序”“源码”分成明确下载项；给用户清晰的启动文件和动作入口；角色图片与配置放在一起。当前项目仍只承诺 Windows 支持，不因为可分享就声称跨平台。

### PetForDesktop：可替换的精灵图集

[PetForDesktop 官方仓库](https://github.com/Renardjojo/PetForDesktop) 说明支持替换水平图集、自定义动画、编辑设置和右键交互。

本项目采用的设计：公开固定图集规格，导入前验证尺寸和透明背景；替换皮肤不必改应用代码。独立版只执行受限的动作/台词配置，不把导入皮肤当作运行任意脚本的授权。这里仅借鉴交互模式，没有迁入该项目依赖或屏幕碰撞检测。

## 小红书展示素材的取舍

本项目预览按 1080×1440 的 3:4 竖图设计，作为便于浏览的展示版式；不宣称这是小红书唯一或强制的上传规格。封面突出真实角色，后续图解释三步使用、动作入口和个性化编辑。视频或 GIF 应直接使用本项目图集的实际帧；展示画面不能冒充已经接入的额外原生功能。

公开发布前，下载说明应直接区分：原生版需要现有 Codex/ChatGPT 桌面应用；独立版无需该应用、具备本项目的手动动作和小工具；图集编辑者需自行确保替换素材的使用与分发权利。
