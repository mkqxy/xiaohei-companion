# 互动声音

猫形应声选自 Luke100000 的八周幼猫实录（30.78–31.42 秒），保留自然音高。[原录音](https://freesound.org/people/Luke100000/sounds/476918/) · [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

包内猫叫 SHA-256 为 ed5abb2f30d8343efa40508607ddf0da5e6dc6e6ef29580eef7b7b4edef673fd。

人形自我介绍和「师父」由 Windows 中文通用语音 Microsoft Huihui 合成并剪辑。这两句为同人桌宠配音。口型根据实际 WAV 的音量包络驱动。默认音频随程序内置，运行时无需安装语音包；可以在声音设置里换成自己录制的短句。呼噜、嘿咻的短应声、进食和专注结束提示由代码生成。
